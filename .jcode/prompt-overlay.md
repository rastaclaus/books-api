# Правила моделирования Value Objects и сдачи задач

- Все Value Objects делай неизменяемыми (`@dataclass(frozen=True, slots=True)`), валидацию инвариантов выполняй в `__post_init__`.
- Нормализуй входные строки в Value Objects (например, убирай крайние пробелы и приводи коды языков/ISBN к каноническому виду) до проверки инварианта, используя `object.__setattr__(self, ...)` внутри `__post_init__`.
- Держи модули компактными и без преждевременных абстракций: никаких фабрик ради фабрик и метаклассов; выноси нетривиальные числовые пороги и длины в именованные константы (чтобы код проходил строгий `ruff` без лишних `# noqa`).
- Никогда не сдавай задачу без финального прогона `just check` и `just test`: в конце каждого ответа давай краткую сводку (до 5 строк), какие инварианты добавлены и каков статус `just check` / `just test`.
- Не коммить без явной команды, дождись результата ревью.
