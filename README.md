# books-api: практикум по работе с jcode

Добро пожаловать в учебный стенд **`books-api`**.

В этом репозитории вы на практике освоите возможности coding-агента **`jcode`** и его настройки уровня проекта, шаг за шагом создавая руками агента лаконичную доменную область бэкенда для сайта свободной раздачи электронных книг.

Никакой возни с базами данных, Docker, миграциями и HTTP-фреймворками: мы сфокусированы исключительно на **чистом доменном слое** (`dataclasses` + `pytest` + строгие `ruff` и `ty` под управлением `just`), чтобы всё внимание уходило на приёмы эффективной работы с `jcode`.

## Что внутри

- **[Начать обучение: `tutorial/README.md`](tutorial/README.md)** (10 практических уроков от базового контракта `AGENTS.md` до кросс-модельного `/autoreview`, Swarm, Lifecycle Hooks и песочниц `jcode run`).
- `pyproject.toml` и `src/books_api/__init__.py`: минимальная стартовая заготовка Python-пакета. Код домена, `justfile`, настройки линтеров и проектные конфиги `.jcode/` намеренно не созданы заранее, вы создадите их вместе с `jcode` по ходу прохождения уроков.

## Быстрый старт

Убедитесь, что у вас установлены `jcode`, `uv`, `just` и `Python 3.14+`:

```bash

uv --version
just --version
python3 --version
```
