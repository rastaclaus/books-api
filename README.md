# books-api: учебный стенд для практикумов по coding-агентам

Добро пожаловать в учебный полигон **`books-api`**.

В этом репозитории вы на практике освоите harness-среду coding-агента — **OpenCode V2** или **`jcode`** — и настройки уровня проекта, шаг за шагом создавая руками агента лаконичную доменную область бэкенда для сайта свободной раздачи электронных книг.

Никакой возни с базами данных, Docker, миграциями и HTTP-фреймворками: мы сфокусированы исключительно на **чистом доменном слое** (`dataclasses` + `pytest` + строгие `ruff` и `ty` под управлением `just`), чтобы всё внимание уходило на приёмы эффективной работы с агентом.

## Что внутри

- **[Карта стенда и выбор трека: `tutorial/README.md`](tutorial/README.md)** — общее описание полигона, сравнение двух курсов и правила прохождения.
- **Трек [OpenCode V2](tutorial/opencode-lessons/README.md)** — 10 практических уроков по нативному workflow OpenCode V2: живой контракт `AGENTS.md`, `opencode.jsonc` и `cli.json`, Plan-режим и steering, снапшоты `/undo`, кастомные команды и скиллы, MCP + Code Mode, кастомные агенты и permissions/policies, параллельные сабагенты и worktrees, плагины и headless-автоматизация.
- **Трек [`jcode`](tutorial/jcode-lessons/README.md)** — 10 практических уроков от базового контракта `AGENTS.md` до кросс-модельного `/autoreview`, Swarm, Lifecycle Hooks и песочниц `jcode run`.
- `pyproject.toml` и `src/books_api/__init__.py`: минимальная стартовая заготовка Python-пакета. Код домена, `justfile`, настройки линтеров и проектные конфиги агентов (`.opencode/`, `.jcode/`) намеренно не созданы заранее, вы создадите их вместе с агентом по ходу уроков.

## Быстрый старт

Убедитесь, что у вас установлены агент (для выбранного трека), `uv`, `just` и `Python 3.14+`:

```bash
opencode --version     # для трека OpenCode V2
# или
jcode version          # для трека jcode

uv --version
just --version
python3 --version
```

## Как проходить курсы

1. Откройте [карту стенда](tutorial/README.md) и выберите трек.
2. Рекомендуется проходить каждый трек в **отдельной ветке Git**, начиная с чистого стартового состояния репозитория:
   ```bash
   git switch -c track/opencode   # для трека OpenCode V2
   # или
   git switch -c track/jcode      # для трека jcode
   ```
3. Идите по урокам выбранного трека строго по порядку: каждый следующий урок опирается на код `books-api` и настройки проекта, созданные в предыдущем.
4. В конце каждого урока фиксируйте прогресс коммитом, чтобы в любой момент видеть чистый `git diff` следующего шага.

Готовы? Переходите к [карте стенда](tutorial/README.md).
