# AGENTS.md: books-api

Учебный проект: чистое доменное ядро каталога свободной раздачи электронных книг.
Контракт для всех агентов; `README.md` предназначен для людей.

## Команды

- Установить окружение: `uv sync`
- Добавить dev-инструменты: `uv add --dev pytest ruff ty`
- Обязательные ворота: `just check` и `just test`
- `just check`: `ruff check .`, `ruff format --check .`, `ty check`
- `just test`: `uv run pytest -q`
- Автоисправление и форматирование: `just fmt`
- Точечный прогон: `just test tests/domain`

## Критические правила

1. Разрабатываем ТОЛЬКО чистую доменную область в `src/books_api/domain/`:
   без HTTP-фреймворков, ORM/SQL, БД, сети и файлового I/O.
2. `dependencies = []` в `pyproject.toml` неизменны. Новые пакеты добавляются
   только через `uv add --dev ...`.
3. Все инструменты запускаются через `uv run ...` или рецепты `just`.
   `pip`, `python -m pip`, системные `pytest` / `ruff` / `ty` и ручная
   активация виртуального окружения запрещены.
4. Перед сдачей любой задачи обязательны `just check` и `just test`:
   ноль замечаний линтера, форматтера и тайпчекера, все тесты зелёные.
5. Нарушение бизнес-инварианта домена выбрасывает исключение-наследник
   `DomainError` (иерархия в `src/books_api/domain/errors.py`);
   `Exception`, `AssertionError` и `ValueError` для бизнес-правил запрещены.
6. Код, идентификаторы, комментарии в коде и сообщения коммитов пишем
   на английском; пояснения пользователю даём на русском.

## Стек и стиль

- Python 3.14+, строгая типизация: аннотации у всех функций, методов и полей.
- Value Objects: `@dataclass(frozen=True, slots=True)`, валидация в `__post_init__`.
- Перечисления: `Enum` / `StrEnum`; никаких магических строк и чисел.
- Порты репозиториев: `typing.Protocol`; реализации живут вне домена.
- Переопределение методов: `@override` из `typing`.
- Иммутабельность: объекты не мутируются, изменение создаёт новый экземпляр.
- Исключения сигнализируют о нарушении инвариантов, а не управляют ветвлением.

## Структура

- `src/books_api/domain/`: сущности, Value Objects, доменные ошибки, порты.
- `tests/domain/`: pytest-тесты, зеркалят структуру домена.
- `tools/`, `scripts/`: вспомогательные утилиты вне домена.

## Тесты

- Только `pytest`: функции `test_*`, фикстуры в `conftest.py`.
- Каждый инвариант покрыт минимум одним тестом; наборы кейсов через
  `@pytest.mark.parametrize`.
- Тесты детерминированы: без сети, `sleep`, случайности и реального времени.
- Публичный API проверяется импортом из `books_api.domain`.

## Запрещено

- Использовать `print` в доменном коде.
- Оставлять `# type: ignore` или `noqa` без кода правила и причины.
- Дублировать правила из этого файла в других документах проекта.
