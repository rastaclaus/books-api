# AGENTS.md — books-api

Учебный проект: каталог свободных электронных книг (чистая доменная область).

## Область разработки

- Реализуем **только** чистую доменную логику в `src/books_api/domain/`.
- Никаких HTTP-фреймворков (FastAPI/Flask), ORM/SQL, внешних runtime-зависимостей:
  `dependencies = []` в `pyproject.toml` не расширяется.

## Стек и стиль

- Python 3.14+.
- Строгая типизация: аннотации везде.
- Value Objects — `@dataclass(frozen=True, slots=True)`.
- Перечисления — `Enum` / `StrEnum`.
- Порты репозиториев — `typing.Protocol`.
- При переопределении методов — `@override`.

## Управление пакетами

- Только `uv`: `uv add --dev pytest ruff ty`.
- Запуск инструментов — через `uv run ...` или рецепты `justfile`.
- Не вызывать голый `pip`, а также системные `pytest` / `ruff` / `ty` напрямую.

## Ворота качества (обязательны перед сдачей задачи)

Перед завершением любого задания агент обязан добиться:

- `just check` — ноль замечаний (`ruff check`, `ruff format --check`, `ty check`);
- `just test` — зелёные тесты (`pytest`).

## Доменные ошибки

Нарушения бизнес-инвариантов выбрасываем осмысленными исключениями,
унаследованными от базового `DomainError`. Не используем общий `Exception`
или `AssertionError`.

## Язык

- Код и идентификаторы — на английском.
- Краткие пояснения пользователю — на русском.

В отчетах о изменениях всегда указывай список изменений в конце - файл, что добавили/изменили, file:lines
